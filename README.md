**VICE HARBOR** — an original open-world crime game set in Port Azura, a sunset city of palm boulevards, market plazas and marina piers, built with three.js and plain ES modules. You are Rio, a driver in debt to the harbour's fixer, Marina Sol. Work her five jobs — steal the pink Marina GT, run a hot package to her yacht, hit eight street checkpoints, extract Nico under full heat, and move three crates in the harbour finale — while the Azura PD's predictive cruisers hunt you on a 0–5 star wanted system with a bust meter, fines and impound respawns.

The city is fully explorable on foot and by car: 24 lane-following traffic cars that queue and turn at junctions, 20 parked cars (every one stealable), 42 pedestrians who stroll, flee and can be knocked down, a punch, a working minimap, a full HUD, procedural WebAudio (engine, sirens, pad, stingers), and a localStorage save. Static files only — it plays offline in a desktop browser with no build step.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```

To hand the entry in the way the grader does: `MAKEFUN_OUTPUT_DIR=out node main.ts` copies `game/` and `screenshots/` into `out/` and writes `out/dossier.json`.
